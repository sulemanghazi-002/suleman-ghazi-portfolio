# Suleman Ghazi Portfolio

Responsive static six-page portfolio.

## Deploy to Vercel
1. Upload this folder to a GitHub repository.
2. Import repository at https://vercel.com/new.
3. Select framework **Other** and root directory of the website.
4. Deploy. No build command or environment variables required.

The enquiry form opens WhatsApp; it does not submit to a backend. Portfolio project tiles are placeholders. Original supplied portrait is included.
